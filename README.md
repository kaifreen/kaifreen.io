# Kaifreen Chauhan — Portfolio Website

A responsive, dark-themed portfolio website for Software Development Internship applications.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

No build tools or dependencies are required. Google Fonts are loaded online; the page uses fallback fonts if unavailable.

## Before publishing
- Verify the GitHub profile URL and add direct repository/demo links to each project.
- Add the exact LinkedIn profile URL (the resume text appears to contain a spelling/URL issue).
- Optionally add a downloadable resume PDF and a professional headshot.
- Review all dates, education details and contact information for accuracy.

## Publish
You can deploy this static site using GitHub Pages, Netlify or Vercel. Upload the contents of this folder as a static site.
